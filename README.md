# Multiprovider_LLM_Evaluation
Evaluation of OpenAI, Anthropic, Gemini, Groq - LLM Evaluation

Overview
A retail banking team is evaluating multiple LLM providers for their AI-powered customer support assistant. Before committing to a vendor stack, they need to compare response quality, latency, and cost across OpenAI, Anthropic (Claude), Google Gemini, and Groq (open-source Llama). In this lab, we set up all four providers, run identical banking queries through each, explore how temperature and reasoning effort control output creativity, and use Pydantic structured outputs to extract reliable, schema-validated data from LLM responses.
